# Infrastructure Change Policy

## Branching Rules
- Infrastructure changes must be made on feature branches.
- Direct changes to main are not allowed.

## Review Rules
- Changes must be submitted through a Pull Request.
- Pull Requests must be reviewed before merging.

## Deployment Rules
- Infrastructure changes must be validated before deployment.
- Approved changes can be merged into main.

## Change Request
- New infrastructure changes require validation on a feature branch.
- Changes must be reviewed before merging into main.
